# 토스(Apps In Toss) 설정 완료 가이드

이 문서는 토스 플랫폼 개발을 위한 모든 설정을 완료하는 가이드를 제공합니다.

---

## 1. 사전 준비사항

### 1.1 앱인토스 콘솔 설정
- [앱인토스 개발자센터](https://developers-apps-in-toss.toss.im/) 접속
- 앱 생성 및 **앱 ID** 발급
- 앱 카테고리를 **게임**으로 설정 (필수)
- 광고 그룹 ID 발급 (인앱 광고 사용 시)
- 인앱 결제 상품 등록 (결제 사용 시)

### 1.2 Unity 프로젝트 확인
- ✅ Unity 2021.3 이상
- ✅ WebGL 빌드 지원 모듈 설치
- ✅ 앱인토스 Unity SDK 패키지 설치 확인 (`Packages/manifest.json`)

---

## 2. Unity Editor 설정

### 2.1 앱인토스 기본 설정

1. **메뉴**: `Apps in Toss > Build & Deploy Window` 실행
2. **Configuration** 탭에서:
   - **App ID**: 앱인토스 콘솔에서 발급받은 앱 ID 입력
   - **Icon URL**: 미니앱 아이콘 URL 입력 (필수)
   - **Loading Screen**: `Assets/AppsInToss/loading.html` 사용 또는 커스텀

### 2.2 빌드 설정

**File > Build Settings**:
- Platform: **WebGL** 선택
- Player Settings:
  - **Company Name**: 회사명
  - **Product Name**: 게임명
  - **Version**: 버전 번호
  - **Compression Format**: Gzip 또는 Brotli 권장

### 2.3 프로젝트 설정 확인

**Edit > Project Settings > Player**:
- **WebGL** 탭:
  - **Compression Format**: Gzip/Brotli
  - **Data Caching**: 활성화 권장
  - **Exception Support**: Full (디버깅용)

## 3. 코드 설정 확인

### 3.1 로그인 타입 설정

`ApplicationManager.cs` (208-212줄)에서 자동으로 WebGL 빌드일 때 토스 로그인을 사용하도록 설정되어 있습니다:

```csharp
#if UNITY_WEBGL && !UNITY_EDITOR
    UserDataManager.Instance.SetLoginInfo(E_LOGIN_TYPE.APPS_IN_TOSS_LOGIN);
#else
    UserDataManager.Instance.SetLoginInfo(E_LOGIN_TYPE.GUEST_LOGIN);
#endif
```

### 3.2 결제/광고 사용

```csharp
// LoginInterface 인스턴스 가져오기
LoginInterface platform = UserDataManager.Instance.GetLoginPlatform();

// 상품 목록 가져오기
var products = await platform.GetProductListAsync();

// 결제하기
platform.PurchaseProduct("coin_100", 
    onSuccess: (orderId) => { /* 성공 처리 */ },
    onError: (error) => { /* 에러 처리 */ }
);

// 광고 로드 및 표시
if (platform.IsAdSupported()) {
    platform.LoadAd("ad_group_id", (success) => {
        if (success) {
            platform.ShowAd("ad_group_id", (showSuccess) => { });
        }
    });
}
```

## 4. MCP 서버 설정 (AI 개발 지원)

**Windows:**
```powershell
scoop bucket add toss https://github.com/toss/scoop-bucket.git
```

**MacOS:**
```bash
brew tap toss/tap && brew install ax
```

### 4.2 Cursor MCP 설정

`.cursor/mcp.json` 파일이 이미 생성되어 있습니다. Cursor를 재시작하면 MCP 서버가 자동으로 연결됩니다.

**활용 방법:**
- 토스 SDK 관련 질문 시 `@docs` 명령 사용

## 5. 빌드 및 배포

### 5.1 로컬 개발 서버

1. **메뉴**: `Apps in Toss > Dev Server > Start Server`
2. 개발 서버가 실행되면 URL이 표시됩니다
3. 토스 앱의 샌드박스 환경에서 해당 URL로 접속하여 테스트

### 5.2 프로덕션 빌드

1. **방법 A (자동)**: WebGL로 빌드하면 **빌드 후 AIT 패키징**이 자동으로 시도됩니다.  
   - **Tools > 토스 빌드 설정**에서 "빌드 후 AIT 파일 자동 생성"을 켜두면 됩니다 (기본값: 켜짐).  
   - **Tools > 토스 빌드 후 AIT 자동 패키징** 메뉴로도 on/off 가능합니다.
2. **방법 B (수동)**: **메뉴** `Apps in Toss > Build & Package` 로 빌드 후 `ait-build/dist/` 생성
3. 빌드 완료 후 `ait-build/dist/` 폴더 확인 → 앱인토스 콘솔에 업로드하여 배포

## 7. 문제 해결

### 로그인 실패
- 앱 카테고리가 **게임**으로 설정되었는지 확인
- WebGL 빌드인지 확인 (`#if UNITY_WEBGL` 체크)
- 콘솔에서 앱 상태 확인

### 결제 실패
- 상품 ID가 콘솔에 등록되었는지 확인
- `processProductGrant` 콜백에서 서버 연동 확인
- 에러 코드 확인 (`INVALID_PRODUCT_ID`, `USER_CANCELED` 등)

### 광고 로드 실패
- 광고 그룹 ID가 올바른지 확인
- `IsAdSupported()` 반환값 확인
- 네트워크 연결 확인

### 명령 실패 (cmd_4 / FAIL_NPM_BUILD) — 'node' is not recognized
- **원인**: Node.js가 없거나, Unity가 켜질 때 PATH에 `node`가 없음.
- **해결**: Node.js LTS 설치 후 **PC 한 번 재부팅**하면 PATH가 적용됩니다. 그 다음부터는 Unity 평소처럼 쓰면 됩니다.

### 명령 실패 (Exit: 1): cmd_5
`AppsInToss.Editor.AITAsyncCommandRunner`에서 **cmd_5**가 실패하면, SDK가 실행하는 **패키징 단계 중 하나(보통 `pnpm run build` / granite·vite 빌드)** 가 실패한 것입니다.

**순서대로 확인:**

1. **Node.js 설치 및 PATH**
   - [Node.js LTS](https://nodejs.org/) 설치 후, **Unity를 완전히 종료했다가 다시 실행**합니다.
   - 터미널에서 `node -v`, `npm -v` 가 동작하는지 확인합니다.
   - Unity는 실행 시점의 시스템 PATH를 쓰므로, Node 설치 후 Unity를 재실행해야 합니다.

2. **pnpm 설치**
   - `npm install -g pnpm` 로 전역 설치 후, `pnpm -v` 로 확인합니다.
   - SDK는 `BuildConfig~` 안에서 `pnpm`으로 의존성을 설치하고 빌드합니다.

3. **수동 빌드로 에러 메시지 확인**
   - 프로젝트 루트에서 WebGL 빌드 출력 폴더(예: `webgl` 또는 `Build`)로 이동한 뒤, SDK가 사용하는 `BuildConfig~` 폴더로 이동합니다.
   - 해당 폴더에서 터미널로 `pnpm install` → `pnpm run build` 를 실행해 보세요.
   - 여기서 나오는 **에러 메시지**가 cmd_5 실패의 실제 원인입니다 (의존성 오류, TypeScript/환경 변수 등).

4. **빌드 후 자동 패키징 비활성화 (우회)**
   - 자동 패키징이 계속 실패하면 **Tools > 토스 빌드 후 AIT 자동 패키징**을 끕니다.
   - WebGL 빌드만 한 뒤, **Apps in Toss > Build & Package** 메뉴로 수동 패키징을 시도하거나, 위 3번에서 수동으로 `pnpm run build` 후 생성된 결과물을 사용합니다.

5. **SDK/문서 확인**
   - [앱인토스 Unity SDK GitHub](https://github.com/toss/apps-in-toss-unity-sdk) 이슈 검색 및 최신 버전 확인.
   - [앱인토스 개발자센터](https://developers-apps-in-toss.toss.im/) Unity 빌드/패키징 문서 참고.
