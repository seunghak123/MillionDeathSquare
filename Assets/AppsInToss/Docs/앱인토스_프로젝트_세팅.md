# 앱인토스(App in Toss) 프로젝트 세팅 가이드

이 프로젝트는 **앱인토스 Unity SDK**를 사용하여 토스 앱 내 WebGL 미니앱으로 빌드·배포할 수 있도록 구성되어 있습니다.

- **공식 유니티 SDK 문서**: [유니티 SDK | 앱인토스 개발자센터](https://developers-apps-in-toss.toss.im/unity/porting-tutorials/unity-sdk.html)
- **설치**: Package Manager → Add package from git URL → `https://github.com/toss/apps-in-toss-unity-sdk.git`
- **API**: `AIT.IAPGetProductItemList()`, `AIT.IAPCreateOneTimePurchaseOrder()`, `AIT.GoogleAdMobLoadAppsInTossAdMob()`, `AIT.GoogleAdMobShowAppsInTossAdMob()` 등 C#에서 직접 호출

## 1. 사전 요약

- **SDK 패키지**: `Packages/manifest.json`에 `im.toss.apps-in-toss-unity-sdk` (Git URL) 등록됨  
- **로그인**: WebGL 빌드 시 `APPS_IN_TOSS_LOGIN`으로 자동 설정되며, `AIT.AppLogin()` → `AIT.GetUserKeyForGame()`로 사용자 키(해시)를 획득해 게임 서버 식별자로 사용  
- **로딩 화면**: `Assets/AppsInToss/loading.html`에서 커스텀 가능 (AIT 메뉴: Reset Loading Screen으로 기본 복구)

## 2. Unity Editor에서 할 일

### 2.1 앱인토스 설정 창

1. 메뉴 **Apps in Toss > Build & Deploy Window** (또는 **AIT > Configuration**) 실행  
2. **앱 ID** 입력 (앱인토스 콘솔에서 발급)  
3. **아이콘 URL** 입력 (필수) — 토스 앱에서 미니앱 아이콘으로 표시됨  
4. 필요 시 빌드 프로필(Dev Server / Production Server / Build & Package) 옵션 조정  

### 2.2 자격 증명(선택)

- 서버 연동·결제 등이 필요하면 **AIT > Configuration** 또는 Editor 폴더의 **AITCredentials** 에셋에서 mTLS 등 설정  
- 앱인토스 콘솔에서 mTLS 인증서 발급 후 해당 경로/설정 반영  

## 3. 프로젝트 구조상 연동 요약

| 구분 | 내용 |
|------|------|
| 로그인 타입 | `E_LOGIN_TYPE.APPS_IN_TOSS_LOGIN` (CommonEnum) |
| 로그인 구현 | `Scripts/Login/AppsInTossLogin.cs` — `LoginInterface` 구현, WebGL에서만 AIT API 호출 |
| 로그인 진입 | `ApplicationManager.UserLogin()` — WebGL 빌드일 때 `APPS_IN_TOSS_LOGIN` 설정 후 `LoginPlatform()` 호출, 성공 시 `UserLoginSuccess()` → BUNDLE_UPDATE |
| 사용자 토큰 | `UserDataManager.SetUserToken()` — `GetUserKeyForGame()` 성공 시 반환된 `hash` 값을 서버 유저 식별자로 사용 |
| 결제 기능 | `LoginInterface.PurchaseProduct()` — 인앱 결제 지원, `AIT.IAP.CreateOneTimePurchaseOrder()` 사용 |
| 광고 기능 | `LoginInterface.LoadAd()` / `ShowAd()` — 인앱 광고 지원, `AIT.GoogleAdMob` API 사용 |
| 플랫폼 접근 | `UserDataManager.GetLoginPlatform()` — 현재 로그인 플랫폼의 `LoginInterface` 인스턴스 반환 |

## 4. 빌드 및 로컬 테스트

- **로컬 개발 서버**: **AIT > Dev Server > Start Server** → Metro/개발 서버 실행 후 앱인토스 샌드박스 앱에서 스킴으로 연결  
- **배포용 패키지**: **AIT > Build & Package** → `ait-build/dist/` 결과물을 앱인토스 콘솔에 업로드  
- **공식 문서**: [앱인토스 개발자센터](https://developers-apps-in-toss.toss.im/)  

## 5. 주의사항

- AIT API(`AppLogin`, `GetUserKeyForGame` 등)는 **WebGL 빌드**에서만 실제 동작하며, 에디터에서는 Mock 로그만 출력됩니다.  
- 에디터/비 WebGL에서는 기존처럼 **GUEST_LOGIN**으로 동작하며, `UserLogin()`에서 플랫폼에 따라 자동 분기됩니다.  
- 게임 카테고리가 아닌 미니앱에서 `GetUserKeyForGame()`을 호출하면 `INVALID_CATEGORY` 등이 반환될 수 있으므로, 앱인토스 콘솔에서 앱 카테고리를 **게임**으로 등록해야 합니다.
