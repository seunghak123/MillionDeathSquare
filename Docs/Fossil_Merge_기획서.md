# [합체퍼즐,캐주얼] Fossil Merge (가제) 게임 기획서

작성일: 2026-10-09 · 기획: 민수님

**한 줄 요약:** 둥근 발굴대 위에 화석을 떨어뜨려 쌓고, 같은 화석끼리 합쳐 더 큰 화석으로 키워 마지막에 공룡 골격을 완성하는 3D 모바일 합체 퍼즐이다. 스킬과 폰 기울기(자이로)로 기존 수박 게임과 다른 재미를 준다. 돈은 광고로 번다.

**이 게임의 재미 3가지**

1. **키우는 재미** — 모래알이 삼엽충이 되고, 삼엽충이 결국 공룡 골격이 된다.
2. **고르는 재미** — 레벨업할 때마다 스킬 3개 중 하나를 골라, 매판 전개가 달라진다.
3. **기울이는 재미** — 상위 모드에서는 폰을 기울여 화석을 굴리고, 지진을 버틴다.

---

## 1. 개요

| 항목 | 내용 |
| --- | --- |
| 장르 | 물리 합체 퍼즐 (수박 게임류) |
| 레퍼런스 | 수박 게임(스이카 게임) 규칙 + 후르츠 마운틴 파티의 3D 접시 쌓기 방식 |
| 플랫폼 | 토스 앱 미니게임 (앱인토스) |
| 엔진 | Unity, 3D (WebGL 빌드) |
| 플레이 타임 | 1판 기본 2분, 점수에 따라 연장 |
| 차별점 | 화석 테마, 공룡 부활, 스킬 5종, 자이로 조작 모드 |
| 수익 모델 | 토스 광고 (보상형 > 전면 > 배너) |
| 모드 | 일반 모드 / 지각 변동 모드(상위, 해금형) |

원작은 Aladdin X의 "스이카 게임"이다. "수박"이라는 이름이나 원작과 비슷한 비주얼은 쓰지 않는다.

## 2. 핵심 루프

한 판 안에서는 "떨어뜨리기 → 합체 → 레벨업 → 스킬 선택"이 반복되고, 11단계까지 키우면 공룡이 부활한다. 판이 끝나면 코인을 받아 로비에서 다음 판에 들고 갈 스킬을 챙긴다.

```
 [ 인게임 (기본 2분) ]
        ┌──────────── 고른 스킬을 들고 계속 쌓기 ────────────────┐
        ▼                                                        │
  ┌────────────┐   ┌──────────┐   ┌────────────┐   ┌────────────┐
  │화석 떨어뜨리기│ ─▶│   합체    │ ─▶│ 경험치 가득 │ ─▶│  스킬 선택  │
  │탭한 위치로 낙하│   │같은 화석끼리│   │합체 점수로 충전│  │3개 중 1개   │
  └────────────┘   └──────────┘   └────────────┘   └────────────┘
        ▲                │ 11단계 완성 시
        │                ▼
        │          ╔══════════════╗
        │          ║   공룡 부활    ║
        │          ║작은 화석 정리 +15초║
        │          ╚══════════════╝
        │ 장착한 스킬을 들고 시작                시간 또는 라이프 소진
 [ 로비 (판과 판 사이) ]                                  │
  ┌────────────┐                  ┌──────────┐   ┌──────▼─────┐
  │  스킬 장착   │ ◀─────────────── │ 코인 획득  │ ◀─│   판 종료   │
  │광고 랜덤·코인 확정│               │점수만큼 지급│   │최종 점수 확정│
  └────────────┘                  └──────────┘   └────────────┘
```

스킬을 많이 챙길수록 더 큰 화석까지 키울 수 있고, 점수가 오르면 시간과 코인이 늘어 다음 판 준비가 쉬워진다.

## 3. 기본 규칙: 3D 발굴대 쌓기

통에 담는 수박 게임과 달리, **벽이 없는 둥근 발굴대 위에 화석을 산처럼 쌓는다.** 화석이 발굴대 밖으로 떨어지면 실수다.

| 항목 | 내용 |
| --- | --- |
| 떨어뜨리기 | 발굴대를 탭하면 그 위치 위에서 화석이 떨어진다 |
| 회전 | 화면을 좌우로 드래그하면 카메라가 발굴대 주위를 돈다 (화면에서는 발굴대가 도는 것처럼 보임) |
| 합체 | 같은 화석 2개가 닿으면 다음 단계 화석 1개로 바뀐다 |
| 연쇄 | 합체로 생긴 화석이 또 같은 화석에 닿으면 연쇄 합체, 점수 배율 상승 |
| 다음 화석 | 화면 구석에 다음에 떨어질 화석 1개를 미리 보여준다 |
| 등장 화석 | 떨어뜨리는 화석은 1~5단계 중 랜덤 (큰 화석은 합체로만 만들 수 있음) |
| 실수 | 화석이 발굴대 밖으로 떨어지면 라이프 -1 |

### 3.1 3D라서 꼭 필요한 장치

- **낙하 위치 가이드:** 떨어질 지점에 그림자와 수직선을 표시한다. 3D는 거리감이 헷갈려서, 이게 없으면 "왜 저기 떨어졌지?" 하는 불만이 생긴다.
- **둥근 돌덩이(노듈) 화석:** 모든 화석을 "둥근 암석 안에 박힌 화석"으로 표현한다. 실제로 화석은 둥근 암석 속에서 많이 발견되고, 공 모양 충돌체를 쓸 수 있어 물리가 안정적이고 가볍다.

## 4. 화석 합체 11단계

작은 생물 화석에서 공룡 화석으로 커지는 흐름이라, 처음 보는 사람도 "다음엔 뭐가 나올지" 직관적으로 기대하게 된다.

```
 ( 1 ) → ( 2 ) → ( 3 ) → ( 4 ) → ( 5 ) → (  6  )
 모래알   조개 화석  삼엽충  암모나이트 물고기 화석  호박(곤충)
                                                 │
   ┌─────────────────────────────────────────────┘
   ▼
 (  7  ) → (  8  ) → (  9  ) → (  10  ) → ((  11  ))
 공룡 알    공룡 이빨   공룡 발톱   공룡 두개골    공룡 골격

 1~5단계: 떨어뜨리는 화석으로 등장
 6~10단계: 합체로만 만듦
 11단계: 완성 시 공룡 부활
```

단계마다 크기와 색을 뚜렷하게 다르게 해, 작은 폰 화면에서도 한눈에 구분되게 한다.

## 5. 게임 모드: 2분 타임어택 + 라이프

한 판은 **2분**으로 시작하고, 정해진 점수를 넘을 때마다 시간이 늘어난다. 라이프 3개가 모두 없어지면 시간이 남아 있어도 끝난다.

### 5.1 기본 규칙

- 시작 시간: 120초
- 시작 라이프: 3개 (화석이 발굴대 밖으로 떨어질 때마다 -1)
- 종료 조건: 시간 소진 또는 라이프 소진 (먼저 도달한 쪽)
- 산이 높아질수록 화석이 굴러 떨어지기 쉬워져, 자연스럽게 난이도가 오른다.

### 5.2 시간 연장: 점수 마일스톤

구간은 점점 넓어지고 보너스는 줄어들어, 판이 너무 길어지지 않는다. 잘하는 유저도 한 판이 대략 4~5분을 넘지 않는 것을 목표로 한다.

| 마일스톤 | 누적 점수 (예시) | 시간 보너스 |
| --- | --- | --- |
| 1차 | 500 | +20초 |
| 2차 | 1,500 | +15초 |
| 3차 | 3,000 | +10초 |
| 4차 이후 | 이전 간격 × 1.5씩 증가 | +5초 |

### 5.3 이어하기 (판당 1회, 보상형 광고)

| 종료 원인 | 이어하기 보상 |
| --- | --- |
| 라이프 소진 | 라이프 1개 회복 + 발굴 브러시 자동 발동 (작은 화석 정리) |
| 시간 소진 | +30초 |

## 6. 공룡 부활

원작에서는 가장 큰 과일을 두 개 합치면 사라질 뿐이다. 이 게임에서는 **11단계 공룡 골격이 완성되는 순간 공룡이 부활한다.**

| 항목 | 내용 |
| --- | --- |
| 발동 | 10단계 두개골 2개가 합체돼 11단계 골격이 되는 순간 |
| 연출 | 골격에 살과 빛이 입혀지며 공룡이 일어나 포효 (약 1.5초, 타이머 정지) |
| 효과 1 | 발굴대 위 1~3단계 작은 화석을 모두 날려버려 공간 확보 (라이프는 깎이지 않음) |
| 효과 2 | 큰 점수 보너스 + 시간 +15초 |
| 효과 3 | 경험치 게이지 가득 채움 → 즉시 스킬 선택 |
| 이후 | 공룡은 사라지고 발굴대에는 남은 큰 화석만 남음 |

한 판에 공룡 부활을 한 번 보는 것이 상위 목표가 되도록, 평균 실력의 유저는 9~10단계까지 도달하는 수준으로 맞춘다.

## 7. 스킬 5종

스킬은 5종이고 모두 1회용이다. 화면 아래의 스킬 버튼을 누른 뒤 대상을 탭하면 발동된다.

| 스킬 | 효과 | 쓰는 상황 |
| --- | --- | --- |
| 망치 | 탭한 화석 1개를 부순다 | 애매한 자리에 끼어 합체를 막는 화석 제거 |
| 발굴 브러시 | 1~2단계 작은 화석을 모두 쓸어낸다 | 자잘한 화석으로 산이 어지러울 때 |
| 지진 | **내가 정한 방향으로** 발굴대를 3초간 흔든다. 흔드는 동안 테두리에 벽이 솟아 화석이 떨어지지 않는다 | 막힌 산을 풀어주거나, 같은 화석을 한쪽으로 모을 때 |
| 자석 | 탭한 화석과 같은 화석을 끌어당겨 합체시킨다 | 멀리 떨어진 같은 화석을 잇고 싶을 때 |
| 진화 (가정) | 탭한 화석을 1단계 업그레이드한다 | 연쇄 합체를 노릴 때 |

### 7.1 지진 조작 방법

1. 지진 버튼을 누른다 → 발굴대 테두리에 벽이 솟는다.
2. 흔들 방향으로 화면을 스와이프한다 (일반 모드). 지각 변동 모드에서는 **폰을 기울이는 방향**으로 흔들린다.
3. 3초 뒤 벽이 내려간다.

### 7.2 규칙

- 한 번에 들고 있을 수 있는 스킬은 **최대 4개**. 가득 찼을 때 새 스킬을 얻으면 하나를 버리고 받는다.
- 스킬이 너무 강하면 원작의 "물리로 인한 운과 실력의 긴장감"이 사라지므로, 스킬은 위기를 넘기는 수단이지 자동으로 이기는 수단이 아니게 설계한다.
- 5번째 스킬은 원래 목록에서 "지진"이 중복돼 있어, **진화로 가정**했다. 레퍼런스 게임에도 "업그레이드" 아이템이 있어 검증된 효과다.

## 8. 스킬 획득: 로비 장착 + 인게임 레벨업

스킬을 얻는 길은 두 가지다. **시작 전에 로비에서 사서 끼고 들어가거나, 판 중에 레벨업해서 고른다.**

| | 로비에서 장착 | 인게임 레벨업 |
| --- | --- | --- |
| 언제 | 게임 시작 전 | 판 중, 경험치 게이지가 가득 찰 때 |
| 어떻게 | 광고 보기 = 랜덤 스킬 1개 / 코인 = 원하는 스킬 1개 확정 | 랜덤 스킬 3개 중 1개 선택 |
| 수량 | 장착 슬롯 2개 | 레벨업마다 1개 |
| 광고 연계 | 광고 보고 스킬 받기 (하루 10회) | 광고 보고 **다시 뽑기** (선택지 3개 새로 받기, 레벨업당 1회) |

### 8.1 경험치와 레벨업

- 합체할 때마다 얻은 점수만큼 경험치 게이지가 찬다.
- 게이지가 가득 차면 게임이 잠깐 멈추고 스킬 3개 중 하나를 고른다 (선택 중에는 타이머 정지).
- 레벨이 오를수록 다음 레벨에 필요한 경험치가 늘어난다. 초반에는 자주, 후반에는 드물게 얻는다.
- 경험치는 판이 끝나면 초기화된다.

### 8.2 왜 두 가지를 함께 쓰나

- **로비 장착**은 "내가 좋아하는 스킬을 들고 간다"는 안정감을 주고, 광고와 코인을 쓸 이유가 된다.
- **레벨업 선택**은 매판 다른 전개를 만들어 반복 플레이 동기가 된다.
- 광고 = 랜덤, 코인 = 확정 규칙은 Fossil Slash의 파츠 구매와 같아서, 두 게임의 경제 시스템을 공통 모듈로 만들 수 있다.

## 9. 지각 변동 모드 (자이로, 상위 난이도)

폰을 기울이면 발굴대도 기울어지는 상위 모드다. 흔들림을 **막을 수도, 일부러 일으켜 합체에 이용할 수도** 있다. 멀미와 난이도 부담이 있어 선택형으로만 제공한다.

### 9.1 일반 모드와 비교

| | 일반 모드 | 지각 변동 모드 |
| --- | --- | --- |
| 폰 기울기 | 사용 안 함 | 폰 기울기로 발굴대를 기울임 |
| 지진 이벤트 | 없음 | 주기적으로 발생 |
| 보상 | 기본 | 점수와 코인 x1.5 |
| 순위표 | 토스 게임센터 순위표 (게임당 1개) | 순위표 없음. 내 최고 기록을 서버에 저장하고 결과 화면에 크게 표시 |
| 해금 | 처음부터 | 일반 모드에서 **N점 이상 달성** 시 (초기값 5,000점) |

로비에는 모드 전환 버튼 하나만 추가한다. 해금 전에는 자물쇠와 "5,000점 달성 시 해금"을 표시해 목표로 삼게 한다.

### 9.2 두 가지 플레이: 막기와 이용하기

| | 막기 (수비) | 이용하기 (공격) |
| --- | --- | --- |
| 상황 | 지진 경보 → 2초 뒤 발굴대가 한쪽으로 기울며 흔들림 | 지진이 없을 때도 언제든 |
| 조작 | 폰을 **반대로** 기울여 균형 잡기 | 폰을 기울여 화석을 원하는 방향으로 굴리기 |
| 보상 | 버티기 성공 보너스 점수 | 굴려서 합체하면 점수 x1.5 |
| 위험 | 못 버티면 화석이 떨어져 라이프 감소 | 너무 기울이면 화석이 떨어짐 |

**지진 스킬과의 연계:** 이 모드에서 지진 스킬을 쓰면 벽이 솟은 동안 폰을 기울이는 방향으로 흔들림을 직접 조종할 수 있다. 자석은 기울기와 겹치면 더 멀리서 끌어당긴다.

### 9.3 지진 이벤트 난이도 (기본 2분 기준)

| 구간 | 지진 간격 | 기울기 강도 | 지속 |
| --- | --- | --- | --- |
| 0~60초 | 30초 | 약 (5°) | 2초 |
| 60~120초 | 20초 | 중 (10°) | 3초 |
| 120초 이후 (연장 시간) | 15초 | 강 (15°) | 4초 |

### 9.4 멀미 방지 (가장 중요)

멀미는 눈에 보이는 화면과 몸이 느끼는 움직임이 어긋날 때 생긴다. 원칙은 하나다: **카메라는 고정하고, 발굴대만 기울인다.**

| 장치 | 내용 |
| --- | --- |
| 카메라 고정 | 폰을 기울여도 배경과 지평선은 그대로, 발굴대만 움직임 |
| 화면 흔들림 최소화 | 지진은 화면 흔들기 대신 진동(햅틱)과 발굴대 흔들림으로만 표현 |
| 흔들림 강도 옵션 | 0~100% 조절, 0%면 시각적 흔들림 완전히 끔 |
| 기울기 한계 | 최대 15° |
| 진입 전 안내 | "기기를 기울여 플레이합니다. 어지러우면 일반 모드를 이용하세요." |

드래그로 카메라가 발굴대 주위를 도는 것은 유저가 직접 조작할 때만 일어나므로 이 원칙과 충돌하지 않는다. 폰을 기울여도 카메라는 움직이지 않는다.

**방향은 화면 기준으로 계산한다.** 카메라가 돌아가 있어도 폰을 왼쪽으로 기울이면 발굴대는 화면 왼쪽으로 기울어야 한다. 지진 스킬의 스와이프 방향도 같다.

### 9.5 조작 편의 장치

| 장치 | 이유 |
| --- | --- |
| 기준 자세 재설정 | 시작할 때 현재 폰 각도를 "수평"으로 인식. 누워서 해도 문제없음 |
| 데드존 (±3°) | 손떨림 정도의 작은 움직임은 무시 |
| 부드럽게 보정 | 센서 값의 튀는 움직임을 걸러 발굴대가 덜덜 떨리지 않게 |
| 감도 옵션 | 낮음 / 보통 / 높음 |
| 자이로 미지원 기기 | 가속도 센서로 대체, 그것도 없으면 모드 비활성화 |

**토스 환경 확인 필수:** 앱인토스 SDK에는 기울기 센서 전용 기능이 없다. Unity WebGL은 브라우저의 기기 방향 정보로 기울기를 읽는데, 이것이 토스 앱 안(특히 iOS)에서 동작하는지는 실제 기기로만 확인할 수 있다. 프로토타입 단계에서 가장 먼저 확인하고, 동작하지 않으면 두 가지 중 하나를 고른다.

- **대체 조작:** 화면 한쪽을 누른 채 끌어서 발굴대를 기울이는 방식
- **모드 보류:** 지각 변동 모드를 2차 업데이트로 미룸

## 10. 재화와 광고 수익 구조

게임 안 돈은 코인 하나뿐이다. 수익의 중심은 **보상형 광고**(유저가 보상을 얻으려고 스스로 누르는 광고)이고, 게임 도중에는 어떤 광고도 띄우지 않는다.

### 10.1 코인

| 구분 | 내용 |
| --- | --- |
| 얻기 | 판이 끝나면 점수에 비례해 지급 (점수 ÷ 50), 지각 변동 모드는 x1.5 |
| 쓰기 | 스킬 확정 구매 (로비) |
| (추후) | 발굴대 스킨, 화석 테마 스킨 등 꾸미기 상품 |
| 기준 | 2~3판 하면 스킬 1개를 살 수 있는 수준 |

### 10.2 광고가 뜨는 곳

| 위치 | 광고 종류 | 유저가 받는 것 | 규칙 |
| --- | --- | --- | --- |
| 로비 | 보상형 | 랜덤 스킬 1개 | 하루 10회 |
| 레벨업 선택 화면 | 보상형 | 선택지 다시 뽑기 | 레벨업당 1회 |
| 게임오버 | 보상형 | 이어하기 (라이프 회복 또는 +30초) | 판당 1회 |
| 결과 화면 | 보상형 | 코인 2배 | 판당 1회 |
| 결과 → 로비 이동 | 전면 (화면 전체 강제 광고) | - | 3판마다 1회, 첫 판과 보상형을 본 판은 제외 |
| 결과 화면 하단 | 배너 (작은 띠 광고) | - | 결과 화면에서만 |
| 게임 중 | 없음 | - | 절대 노출 금지 |

레벨업 "다시 뽑기"는 판 안에서 여러 번 나오는 광고 자리다. 원하는 스킬이 안 나왔을 때의 아쉬움이 자연스럽게 광고 시청으로 이어진다.

**토스 광고 기준:** 토스 광고는 보상형, 전면, 배너를 모두 지원하므로 위 배치는 그대로 쓸 수 있다. 보상형은 "보상 획득" 신호가 온 뒤에만 보상을 준다. 광고는 토스 앱 안에서만 나오므로, 테스트도 토스 앱에서 해야 한다. 노출 빈도 제한은 문서에 없어 토스 콘솔에서 확인한다.

## 12. 3D 아트 & 기술 사양

로우폴리(면이 적고 단순한 3D) 모델에 만화 느낌의 색을 입힌다. 물리 계산이 많은 장르라 **가벼움과 안정성**을 최우선으로 한다.

| 항목 | 결정 | 쉽게 말하면 |
| --- | --- | --- |
| 렌더링 | Unity 기본 렌더링 (현재 프로젝트 설정), 툰 느낌은 셰이더·텍스처로 | 토스 앱(WebGL)에서도 가볍게 도는 설정 |
| 카메라 | 비스듬히 내려다보는 각도, 드래그하면 카메라가 발굴대 주위를 돈다 | 판을 직접 돌리면 마찰 때문에 화석이 미끄러져서 카메라를 돌린다. 화면에서는 같아 보임 |
| 물리 | Unity 물리 엔진, 화석은 구(공) 충돌체 | 둥글게 처리해 굴러가는 방식이 예측 가능 |
| 물리 안정화 | 멈춘 화석은 계산 중지(슬립), 동시 화석 수 상한 40개 | 화석이 많아져도 느려지지 않게 |
| 합체 처리 | 두 화석이 닿으면 중간 지점에 다음 단계 생성 | 원작과 같은 규칙 |
| 낙하 가이드 | 낙하 지점 그림자 + 수직선 | 3D 거리감 보완 |
| 자이로 입력 | Unity WebGL의 기기 방향·가속도 입력 (토스 앱 안 동작 확인 필요) | 폰 기울기 감지, 방향은 화면 기준으로 계산 |
| 목표 프레임 | 중급 기기 60fps (WebGL 물리 성능 확인 후 조정) | 초당 60번 화면 갱신 |
| 광고 SDK | 앱인토스 SDK의 토스 광고 (보상형·전면·배너) | 토스 앱 안에서만 광고가 나옴. 에디터·일반 브라우저에서는 테스트 불가 |

### 12.1 토스 출시에 따른 사양

| 항목 | 내용 |
| --- | --- |
| 빌드 | Unity WebGL로 빌드해 토스 앱 안 미니앱으로 동작 |
| 용량 | 업로드 번들 100MB 이하 (압축 전 기준). 3D 리소스 용량 관리 필요 |
| 순위표 | 토스 게임센터 순위표는 게임당 1개. **일반 모드 점수만 등록**한다. 게임 프로필이 생기기 전에 등록하면 오류가 날 수 있어 순서를 지킨다 |
| 기본 저장 | 코인, 보유 스킬, 설정 등은 토스 저장소(Storage)에 저장. 이 저장소는 기기에만 있어 토스 앱을 지우면 함께 사라진다 |
| 지각 변동 기록 | 기기가 아니라 **자체 서버에 토스 로그인 사용자 기준으로 저장**. 토스는 서버 저장 기능을 주지 않아 가벼운 서버가 필요하다 |
| 코드 이름 | 저장 키, 분석 이벤트 이름, 씬·에셋 이름에 "Suika"를 쓰지 않는다. 내부 클래스 이름은 출시 전에 정리한다 |

## 14. 밸런스 초기값

아래 숫자는 모두 시작점이다. 테스트 플레이로 조정한다. 목표는 **평균 실력 유저가 한 판에 스킬 3~4개를 얻고, 9~10단계까지 도달**하는 것이다.

| 분류 | 항목 | 초기값 |
| --- | --- | --- |
| 모드 | 시작 시간 | 120초 |
| 모드 | 시작 라이프 | 3 |
| 모드 | 시간 연장 마일스톤 | 500 / 1,500 / 3,000점 → +20 / +15 / +10초 |
| 합체 | n단계가 되는 합체 점수 | n × (n+1) ÷ 2 × 10 (예: 3단계 = 60점) |
| 합체 | 연쇄 배율 | 2연쇄 x1.2, 3연쇄 x1.5, 4연쇄 이상 x2 |
| 합체 | 떨어뜨리는 화석 | 1~5단계 랜덤 |
| 공룡 부활 | 보너스 | 2,000점 + 15초 |
| 스킬 | 로비 장착 슬롯 | 2 |
| 스킬 | 최대 보유 | 4 |
| 스킬 | 레벨업 필요 경험치 | 300 → 레벨마다 × 1.6 |
| 스킬 | 지진 지속 | 3초 |
| 지각 변동 | 해금 점수 | 일반 모드 최고점 5,000점 |
| 지각 변동 | 보상 배율 | 점수·코인 x1.5 |
| 지각 변동 | 기울기 최대 / 데드존 | 15° / ±3° |
| 경제 | 코인 지급 | 점수 ÷ 50 |
| 경제 | 스킬 확정 구매 | 150 코인 |
| 광고 | 로비 스킬 광고 하루 한도 | 10회 |
| 광고 | 전면 광고 간격 | 3판마다 |

## 15. 남은 결정 & 다음 단계

### 15.1 아직 정하지 않은 것

- [ ] **토스 앱 안에서 기울기 센서가 동작하는지 실기기 확인 (iOS·Android, 프로토타입 최우선)**
- [ ] 지각 변동 기록을 저장할 자체 서버 범위와 비용
- [ ] 아트 작업 전 렌더링 방식 확정 (현재: 기본 렌더링)
- [ ] 5번째 스킬 확정 (현재 가정: 진화)
- [ ] 정식 게임 이름 (현재 가제: Fossil Merge)
- [ ] 부활하는 공룡 종류: 한 종류로 고정 / 판마다 다르게
- [ ] Fossil Slash와 화석·공룡 에셋 공유 여부
- [ ] 토스 콘솔의 광고 노출 빈도 정책 확인

### 15.2 다음 단계

1. **프로토타입:** 발굴대 쌓기, 합체, 타이머·라이프, 스킬 5종을 임시 그래픽으로 만들어 물리 손맛 확인
2. **레벨업 선택** 흐름과 스킬 강도 테스트
3. **지각 변동 모드**: 여러 기기에서 자이로 감도와 멀미 여부 테스트
4. **로비·코인·광고** 연결 후 소프트 런칭(일부 지역 시범 출시)

### 15.3 용어 정리

| 용어 | 뜻 |
| --- | --- |
| 발굴대 | 화석을 쌓는 둥근 판. 벽이 없어 밖으로 떨어질 수 있다 |
| 노듈 | 화석이 들어 있는 둥근 돌덩이. 게임의 모든 화석은 이 모양이다 |
| 합체 | 같은 화석 2개가 닿아 다음 단계 화석 1개가 되는 것 |
| 연쇄 | 합체로 생긴 화석이 연이어 또 합체되는 것 |
| 공룡 부활 | 11단계 골격 완성 시 일어나는 보너스 이벤트 |
| 레벨업 | 경험치 게이지가 차서 스킬을 하나 고를 수 있게 되는 것 |
| 자이로 | 폰이 얼마나 기울었는지 감지하는 센서 |
| 지각 변동 모드 | 폰 기울기와 지진 이벤트가 추가된 상위 난이도 모드 |
| 마일스톤 | 시간을 더 받을 수 있는 점수 기준선 |
