# 단일 씬 — 필요한 오브젝트

이 프로젝트는 **단일 씬**으로 동작합니다. 씬 로드 없이 한 씬 안에서 화면(인트로/타이틀/로비/인게임)을 전환합니다.

---

## 1. 씬 구조 요약

- **씬 1개**: 매니저 + 모든 화면(뷰) 루트를 한 씬에 배치.
- **화면 전환**: `SceneManager.ChangeScene()` 호출 시 실제로는 **해당 뷰 루트 활성화/비활성** 또는 **UIManager PushUI**로 전환 (구현 시 씬 로드 대신 뷰 스위칭).

---

## 2. 단일 씬에 넣을 오브젝트

### 2.1 매니저 (항상 유지)

| 오브젝트/이름 | 설명 |
|---------------|------|
| **Managers** (루트 빈 오브젝트) | 싱글톤 매니저 부모. `UnitySingleton`이 `GameObject.Find("Managers")`로 찾아 자식으로 붙음. |
| **ApplicationManager** | `managersObject`에 Managers 할당 → `DontDestroyOnLoad(managersObject)` |
| **SceneManager** | 화면(뷰) 전환 담당 |
| **UIManager** | `baseCanvasObject`에 BaseCanvas 할당 |
| **BaseCanvas** | UI 루트. `windowUIParent`, `popUpUIParent`, `utilUIParent`, `effectParent` 4개 Transform 할당 |
| (선택) **GameResourceManager**, **SoundManager** 등 | 프로젝트에서 쓰는 매니저 |

### 2.2 화면(뷰) 루트 — 한 씬에 모두 배치

각 “화면”은 **루트 오브젝트 하나**로 묶고, 전환 시 그 루트만 SetActive(true/false) 하거나, UI는 UIManager로 띄우고 게임 월드는 해당 루트만 켜는 방식으로 처리합니다.

| 뷰 루트 (예: 이름) | 포함할 것 | 비고 |
|--------------------|------------|------|
| **IntroView** (또는 Intro) | IntroSceneController, 인트로 Animation(introPlayer) | 인트로 끝나면 타이틀(게임시작) 뷰로 전환 |
| **TitleView** / **GameStartView** | (선택) TitleSceneController. UI는 UIManager가 GameStartWindow 프리팹으로 표시 | [시작하기] → 인게임 뷰로 전환 |
| **LobbyView** | (선택) LobbySceneController. UI는 LobbyWindow 프리팹 | 로비 전용 UI/오브젝트 |
| **InGameView** | InGameSceneController, CrossyRoadBootstrap, 플레이어, 카메라, MapGenerator, ObjectPool, 맵 루트, PatternManager 등 (아래 표 참고) | 길건너 친구들 플레이 영역 |

- **인게임(길건너 친구들) 전용 오브젝트**  
  CrossyRoadBootstrap, CrossyRoadPlayerController, CrossyRoadCamera, CrossyRoadGameManager, MapGenerator, PatternManager, CrossyRoadObjectPool, 맵 루트 Transform, Row/장애물 프리팹 참조 등 — 기존 GDD·CrossyRoad 스크립트와 동일하게 InGameView 하위에 배치.

---

## 3. 화면 전환 (단일 씬)

- **인트로 → 타이틀(게임시작)**: IntroView `SetActive(false)`, TitleView `SetActive(true)` + `UIManager.PushUI(GameStartWindow)` 등.
- **게임시작 → 인게임**: GameStartView 비활성, InGameView 활성 + 게임 시작 로직(CrossyRoadBootstrap 등).
- **인게임 → 로비/타이틀**: InGameView 비활성, LobbyView/TitleView 활성 + UI 전환.

(실제 전환 코드는 SceneManager 또는 전용 ViewManager에서 `E_SCENE_TYPE`에 따라 위 뷰 루트만 켜고 끄도록 구현.)

---

## 4. Build Settings

- **빌드에 넣는 씬**: 위 단일 씬 **1개**만 넣으면 됨.
- **첫 로드 씬**: 이 단일 씬을 맨 위에 두고 플레이.

---

## 5. 참고

- UI 윈도우/팝업은 **프리팹**(Resources 또는 번들)으로 두고, 씬에는 매니저·캔버스·뷰 루트만 두는 구조.
- 오브젝트는 **에디터에서 세팅**하는 것이 원칙이며, `new GameObject()` 등 코드 생성은 사용하지 않음 (`.cursor/rules/unity-ui-patterns.mdc`).
